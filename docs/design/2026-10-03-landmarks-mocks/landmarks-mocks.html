2. How the outlines look

All three draw on the real page: header, the "Główna" navigation, main, the search form, the two named sections (regions) and the footer. Every outline carries its label as text, so colour is never the only cue. Labels are drawn with content: attr(...) / "", so screen readers skip them; the list carries the same text.

2A Hue, line style and a label tab, like the APG page

Each landmark type has a hue and a line style (solid, dashed, double, dotted) and a filled tab with role and name. Closest to the W3C page the brief points at.

3. The list: the same information as text

Required, not optional: a blind or low-vision user gets nothing from the outlines. Each row is a button that moves focus to the landmark or heading, the way a screen reader jumps with D or H. The warnings come from the same scan.

4A + lesson quiz 4A, plus a lesson in the developer path whose quiz is about this frame

The practice part without new mechanics: a lesson "Punkty orientacyjne i nagłówki" in Ścieżki links to the example with ?symulacja=punkty-orientacyjne, and its quiz asks what the broken frame is missing. The existing quiz component does the checking and keeps the score. A self-ticking task list inside the example (like the pattern exercises) was considered and dropped: the tool cannot point at something that is missing, so "find the missing main" has nothing to click.
