5. Accessibility

  • One h1 "Kontakt", the Notion sections as h2. The existing axe scan checks the heading order.
  • The link text is the address itself, so it says where it goes (2.4.4).
  • Links in the nav, the footer and the B/C rows are 44 px high (2.5.5). Links inside paragraphs are inline and fall under the inline exception.
  • The current nav item: bold, underline and aria-current="page", not colour alone (1.4.1). No code change; Link already does it.
  • B: the message after copying is in role="status" (4.1.3), focus stays on the button, the ✓ icon is aria-hidden. The message does not disappear on its own.
  • A long address wraps (overflow-wrap: anywhere), with no horizontal scrolling at 320 px (1.4.10).
  • Colours only from the existing tokens, which meet 7:1 for text.
  • Nine nav items: on a phone the list wraps onto another row, as it does today. At about 1000 px the desktop row is close to full; I check with screenshots at 1024 and 768 px.
