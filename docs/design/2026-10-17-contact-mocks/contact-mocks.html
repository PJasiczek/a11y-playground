Mocks: contact page edited in Notion

A new page at /kontakt. Its text lives in Notion as strony/kontakt, like the privacy policy, and reaches the site through the existing webhook and import. Linked from the main navigation and the footer. Only an e-mail address and links, no form. Pick a variant: A, B or C. Each one is shown on desktop in the light theme and on a phone in the dark theme. Colours, type and sizes come from src/styles.css, so nothing here adds a token.

The address and profile links are placeholders. The final wording is yours to write in Notion; the copy here only shows how the layout carries it.

Plan: docs/design/2026-10-17-contact-page/contact-page.en.html

A. Plain text, like the privacy policy (recommended)

  • The whole page is Markdown from Notion, rendered with the existing .prose styles. The address is an ordinary link in the text, the profiles a list.
  • Code: one route and one server function. Nothing new to style or test beyond the a11y scan.
  • Trade-off: the address does not stand out more than any other link.

B. The address first, with a copy button

  • The address comes from the yaml block in Notion (email:) and is shown large, above the text. "Kopiuj adres" copies it for people without a mail program set up, where mailto: does nothing.
  • After copying, "Skopiowano adres" appears in a role="status" region, so screen readers announce it (4.1.3). The text stays; it is not a toast that disappears.
  • Code: a frontmatter field for this page, one small client component, a unit and an e2e test.

C. A list of channels

  • The channels come from the yaml block in Notion (links:, each with a label, an address and an optional note) and render as rows: label in the mono caps the app uses for codes, the address as a large link. The rest of the Notion text follows as prose.
  • Every channel looks the same, so adding Mastodon or a second address is one line in Notion.
  • Code: a typed frontmatter list for this page, one list component, a unit test.

Shared by all variants

  • Nav: "Kontakt" is the ninth and last item of "Główna". On a phone the list already wraps instead of hiding behind a menu; it gets one more row (see the phone frames). At about 1000 px the desktop row is close to full; the build step checks 1024 px and 768 px with screenshots.
  • Footer: "Kontakt" goes first, before "Polityka prywatności" and "Ustawienia cookies". Same 44 px link height as today.
  • Headings: one h1 "Kontakt", then h2 sections from Notion. No skipped levels.
  • No date: unlike the privacy policy, "Ostatnia zmiana" is not shown; it means nothing on a contact page.
  • Links in the text (A, and the prose under B and C) are inline, so they fall under the inline exception of 2.5.8 and 2.5.5. Links in the nav, footer, B and C rows are 44 px high.
