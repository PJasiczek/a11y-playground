---
term: piksel CSS
also: [px]
normative: piksel CSS
status: szkic
---
Jednostka `px` z CSS. Nie jest równa fizycznemu pikselowi ekranu: na ekranach o dużej gęstości jeden piksel CSS to kilka pikseli fizycznych.

Kryteria mierzące rozmiar, na przykład celów dotykowych albo szerokości ekranu przy powiększeniu, podają wartości właśnie w pikselach CSS.
